AI Customer Churn Prediction

Project Overview

AI Customer Churn Prediction is a machine learning-based project that predicts whether a customer is likely to leave a service.

Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Flask
- HTML and CSS

Project Features

- Customer dataset analysis
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Machine learning model training
- Logistic Regression and Random Forest
- Customer churn prediction
- Flask-based web application

Dataset

Telco Customer Churn Dataset.

How to Run

1. Install the required Python libraries.
2. Open the project folder in VS Code.
3. Run:

"python app.py"

4. Start the web application:

"python web_app.py"

5. Open "http://127.0.0.1:5000" in your browser.

Project Goal

To identify customers who may leave a service and help businesses improve customer retention.
